On 2026-11-06 the user rejected the first cheat build (lobby rule + a cheat bar with buttons and hotkeys G/M/C/1-0). They want **typed cheat codes** in a type box. The genre mechanic is fine, but GTA's actual codes and names must not be reused.

**User decisions (2026-11-06)**
- The lobby "Cheats" rule is the only room-wide switch. The type box only exists when it's on.
- Each player turns on their own cheats by typing. No lobby opt-in or consent step.
- Each code can be claimed by only one player.
- Everyone sees what each player is typing, live, letters and all. It goes through a server relay message and is display only, outside the sim. Only the submitted code becomes a cheat input (5 bits, at most 31 ids).

**My proposals (pending the user's answer)**
- Codes: HOLYCOW (10 s god + lifts curse, replaces the GOD toggle and CURE), BUMPERCROP (max out), TOPSYTURVY (opponents Reversed 6 s), POPCORN (every ground orb goes off), RAINDANCE (6 tiles get the crate roll; replaces the 13 power-up cheats), COLDSNAP (grass acts and draws as ice for 8 s), LIGHTSOUT (darkness for everyone else for 8 s).
- Claims last one round, and each player gets one claim per round, so the fastest typist can't hoard and every round becomes a draft.
- Live typing appears in the name tag (Night Farm's tag hiding rule already stops leaks) and on the scoreboard card. Each code in the list under the box fills in the typer's seat colour.
- Enter opens the box and your farmer stands still while it's open, so typing is a risk. Enter submits, Esc leaves. Gamepad players can't type, which is acceptable.

**Why:** the user wants cheats to feel like typing a secret code, not like clicking a menu.
**How to apply:** don't re-pitch the bar or hotkeys. Check which of the pending items were built before you build on them. Related: [[project-identity-proposals]].
